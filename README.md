# Primeiro App Android 2026

Aplicativo Android desenvolvido em Kotlin com layout XML, como atividade da disciplina de Programação Mobile.

## O que o app faz

- Tela com um campo de **e-mail** e um campo de **senha** (o texto da senha fica oculto).
- Ao clicar no botão **Entrar**, os dois valores digitados aparecem em um **Toast**, neste formato:

        Email: exemplo@teste.com
        Senha: 123456

Não há validação de e-mail nem de senha. O app apenas exibe o que foi digitado.

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no **Android Studio**.
3. Aguarde a sincronização do Gradle (File > Sync Project with Gradle Files).
4. Escolha um emulador ou um celular Android conectado.
5. Clique em **Run**.

## Tecnologias

- Kotlin
- Layout XML (ConstraintLayout)
- ViewBinding
